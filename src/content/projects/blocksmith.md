## The idea
Agencies often install a page builder just for a few blocks like pricing tables and FAQs. Blocksmith provides those blocks natively, without the extra weight.

## What I built
- Pricing table, FAQ accordion (with FAQ schema), testimonial slider and comparison table blocks
- Every block uses `block.json` and loads its assets only when it's on the page
- Style variations that follow the active theme's colours and fonts

## Result
Clients edit everything in the native block editor, and pages stay fast because no page builder is needed.
