## The idea
Architecture firms live and die by their portfolio, but most of them can't update their own website. Studio Arc is a concept site designed around easy project publishing.

## What I built
- A **Projects** custom post type with fields for location, year, area and project type (ACF)
- An archive filterable by type and year, without page reloads
- A full-width image gallery block with keyboard and swipe support
- Custom block patterns so every project page keeps the same layout

## Result
Publishing a new project takes one form and a few images. The design stays consistent however many projects are added.
